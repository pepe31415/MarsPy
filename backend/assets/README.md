# Assets

Colocar los assets del juego en estos directorios:

## backgrounds/
Background images for each level (JPG or PNG):
- `intro.jpg` — Level 0 intro screen
- `level1.jpg` — Level 1
- `level2.jpg` — Level 2
- `level3.jpg` — Level 3
- `level4.jpg` — Level 4
- `level5.jpg` — Level 5
- `victory.jpg` — Victory screen

**Recommended size**: 1920x1080px, dark/sci-fi themed

## badges/
Badge images for each level (PNG with transparency recommended):
- `welcome.png` — Level 0: Cadete Iniciado
- `oxygen.png` — Level 1: Técnico de Oxígeno
- `sensor.png` — Level 2: Técnico de Sensores
- `emergency.png` — Level 3: Oficial de Emergencias
- `inventory.png` — Level 4: Gestora de Inventario
- `navigator.png` — Level 5: Navegante Estelar
- `hero.png` — Level 200: Héroe de la Estación

**Recommended size**: 128x128px

## Using placeholder images
If you don't have images yet, the game will show fallback icons.
You can use free assets from:
- https://pixabay.com (backgrounds)
- https://game-icons.net (badge icons)
- https://unsplash.com (space/sci-fi backgrounds)
